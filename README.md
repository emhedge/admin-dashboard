# admin-dashboard
Created a basic admin dashboard that demonstrates knowledge of CSS Grid and Flexbox.

I created a color palette with https://coolors.co/image-picker based on an image from Land O'Lakes, Inc. at https://unsplash.com/photos/three-young-people-walk-through-a-dry-grassy-field-o8gGuhfjB2M.
This palette served as the basis for my coloring theme throughout the dashboard.

I named the fake website Truffle and gave it a pig icon, as I imagined the site to be a SAAS platform for log analysis and anomaly detection. Just as a pig has a sensitive enough nose to sniff out and uncover hard-to-find truffles, the tool would be able to analyze logs and identify anomalies. 

The content's theme is based on the Expanse book series (https://en.wikipedia.org/wiki/The_Expanse_(novel_series)), wherein a major character, Josephus Miller, is tasked with analyzing a large collection of data while tracking down a missing person, Juliette Mao (whose middle name is Andromeda).

All animal icons come from https://www.svgrepo.com/collection/cute-animal-vectors/.
